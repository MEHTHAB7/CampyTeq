# CampyTeq Mobile Application (React Native / Expo)

> Scheduled for Phase 10 implementation.

## Overview
A dedicated cross-platform mobile application for students, communicating directly with the CampyTeq Django REST API.

## Core Features (Phase 10)
- Student authentication & biometrics (local device)
- Timetable & Next class
- Real-time Attendance percentage
- Assignment downloads and submissions
- Fee dues and simulated UPI/Card payments
- Print shop queue status
- Library dues
- Push notifications via FCM

## Privacy Guarantee
The mobile application will **never** perform continuous GPS tracking of the student. Location presence is only recorded via institutional authorized campus cameras at designated campus zones.
